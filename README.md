# KashMakr — Enterprise Deliverables Showcase

Live, interactive, fully client-side demos of enterprise-grade software compiled by KashMakr.
Each demo runs entirely in the browser (no backend, no API calls) and corresponds to a
deliverable that passed an independent false-pass audit with a True Pass verdict.

Every demo was verified in a real headless browser (button clicks produce real computed
results, not placeholder output) using `Engine/verify_demos.cjs`.
